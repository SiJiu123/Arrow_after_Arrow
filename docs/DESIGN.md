# 设计说明

## 产品定位

这是一个供课程作业演示的单格箭头解谜游戏。首要目标是让玩家一眼看懂“箭头向哪里飞、为什么被挡住”，并让提交者能够清楚解释路径检测和状态切换。

## 视觉规范

主题采用“纸面棋局”的米白简约风。视觉重点放在棋盘与箭头的方向，不使用外部图片素材。

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 纸面米白 | `#F3EEDF` | 页面背景 |
| 棋盘浅纸色 | `#FBF8EF` | 棋盘与面板 |
| 炭黑 | `#292824` | 主文字与箭头 |
| 石灰灰 | `#C9C1AF` | 网格与次要信息 |
| 鼠尾草绿 | `#66866A` | 成功与主要按钮 |
| 砖红 | `#B55445` | 碰撞、失败与失误提示 |

中文优先使用系统自带的微软雅黑，数字和英文字母使用同一字体，降低不同电脑上的字体缺失风险。标题、状态数字和正文通过字号与字重建立层级。

## 界面结构

```text
┌──────────────────────────────────────────┐
│  一箭又一箭              规则 / 开始游戏 │  开始界面
│            四方向箭头组成的题目标记      │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│  第 1 关     剩余 8 支     失误 3 次     │
│                                          │
│               ┌──────────┐               │
│               │  游戏棋盘 │               │
│               └──────────┘               │
│         重新开始              返回首页    │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│               本关完成 / 挑战失败         │  结果浮层
│              下一关 / 重新挑战            │
└──────────────────────────────────────────┘
```

整体居中对齐，顶部状态栏按固定位置排列。棋盘边界比内部网格更深，箭头采用程序绘制的线段和三角箭头，避免 Unicode 字形在不同电脑上不一致。

## 交互原则

- 成功点击：箭头沿自身方向飞出，原格随后消失。
- 受阻点击：箭头向前轻撞、变红、退回，失误次数减 1。
- 飞行动画期间其他箭头保持可点；受阻箭头在碰撞期间防重复扣错，阻挡解除后允许立即重试并取消碰撞动画。
- 结果浮层保留当前棋盘作为上下文，并提供明确的下一步按钮。
- 所有主题常量集中存放，后续替换配色、字号和圆角不影响游戏规则。

## 设计复核

米白背景是用户明确选择。为避免成为通用卡片模板，界面使用“纸面棋局”概念：棋盘是主视觉，方向箭头构成标题标记；面板只在承载状态或结果时出现，不把每条信息都装进独立圆角卡片。动画只响应玩家点击，不添加无目的的循环动效。
