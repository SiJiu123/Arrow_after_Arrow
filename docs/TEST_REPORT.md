# 测试报告

环境：Windows / Python 3.12.14 / pygame-ce 2.5.6。测试采用unittest，界面使用SDL离屏驱动。测试数量和运行时间以[evidence/verification.json](evidence/verification.json)为准，逐项输出见[tests.txt](evidence/tests.txt)。

| 编号 | 场景 | 预期 | 本轮自动验证 | 限制 |
| --- | --- | --- | --- | --- |
| T01 | 无阻挡点击 | 删除并启动飞出 | 通过：规则删除、坐标点击产生并行动画 | 动画流畅度待本人观察 |
| T02 | 有阻挡点击 | 保留、减1、反馈 | 通过：扣错、碰撞渲染、重复点击保护 | 反馈观感待本人观察 |
| T03 | 四向边缘箭头 | 无越界消除 | 通过：四方向边缘用例 | 无 |
| T04 | 清空与下一关 | 结果页、切换、最终完成 | 通过：从首页逐关点击全部新布局及下一关按钮 | 非真实鼠标硬件事件 |
| T05 | 失误耗尽 | 失败并可重试 | 通过：3次碰撞、失败页、点击重试恢复3次机会 | 无 |
| T06 | 游戏中重开 | 恢复布局和次数 | 通过：普通重开及飞行动画期间重开，清空旧动画 | 无 |
| T07 | 碰撞期间清除阻挡 | 原箭头立即可重试 | 通过：200ms移开阻挡、210ms重试，不等待430ms | 无 |
| T08 | 结果页返回首页 | 后续帧保持首页 | 通过：普通通关、全部通关、失败 | 无 |
| T09 | 关卡可解性 | 三关可解，无解环被拒绝 | 通过：完整消除、纯环和残余环 | 可解不等于难度合适 |
